BRACE is a full scale development project requiring a multi-layered software solution.

The date powering BRACE is stored as XML and the presentation layer is be based on an ASP and XSL.

First all the HTML developed in the prototyping and template making stages had to be translated to XHTML. Then XSL was used to call out pieces of information from the XML database. ASP was used as middle-ware passing variables to the Comm Objects that interface with the database.

Could I do this again on my own? Certainly not! Did I learn things that would make me a more useful member of a development team? Absolutely.
ALTHOUGH 5 OF MY FIRST 10 DAYS ON THE JOB WERE SPENT CRAMMING ASP THE DOCUMENT OBJECT HAS ALWAYS MADE MORE SENSE ON A GLOBAL LEVEL.
